# Quanto Cobro? — Fluxo de usuário

Entrada
→ usuário abre a calculadora
→ se já houver referência financeira local, reutiliza; se não houver, ela é solicitada quando necessária

1. Situação
→ Novo trabalho
→ Alteração / mudança de escopo
→ Prazo urgente
→ Projeto que voltou

2. Esforço
→ informar tempo estimado
→ considerar produção + comunicação + revisões + preparação/entrega
→ se houver incerteza, registrar nível de segurança/faixa em vez de “complexidade”

3. Base financeira
→ usar valor/hora salvo OU informar/calcular valor/hora
→ freelancer profissional: renda desejada + custos + reserva + impostos ÷ horas faturáveis
→ empregado + freela: meta de renda extra + custos ÷ horas disponíveis; salário é contexto, não multiplicador automático

4. Condições
→ verificar revisões adicionais, mudança de escopo, retomada e impacto real da urgência/disponibilidade
→ não aplicar sobretaxa automática quando o evento puder ser representado por horas adicionais

5. Resultado
→ mostrar referência
→ mostrar faixa apenas quando houver incerteza calculada
→ permitir ajustar preço e exibir hora efetiva
→ “Entenda o cálculo” fechado por padrão

6. Saída
→ Copiar mensagem
→ Gerar orçamento
→ Comparar proposta do cliente (NEXT)
→ Fazer outro cálculo

7. Pós-trabalho (LATER)
→ registrar valor cobrado
→ registrar horas reais
→ comparar estimado × realizado
→ melhorar referência pessoal futura
